# **App Name**: Ulyanova Cafe Express

## Core Features:

- Drink Menu Display: Display drink menu with item details (name, description, ingredients, price).
- User Profile & Loyalty Display: Allow registered users to view their profile, bonus balance, and loyalty percentage.
- Customer Order Placement: Enable users to place coffee orders from the displayed menu, calculating total amount with discounts
- Order Confirmation & Status: Display order confirmation and estimated pick-up time for customers.

## Style Guidelines:

- Primary color: Burnt Sienna (#E9724C) to evoke a sense of warmth and the inviting aroma of coffee.
- Background color: Light Peach (#FAE5D4), a desaturated tint of burnt sienna to maintain a gentle and comforting feel without overwhelming brightness.
- Accent color: Deep Mustard (#D4A62C), adds a pop of flavor and stimulates appetite. Used sparingly to draw attention to key elements and CTAs.
- Body and headline font: 'PT Sans' (sans-serif) is used for a modern, readable look across the app.
- Use line icons to represent menu items and actions, keeping a clean, minimalist style.
- A clean, card-based layout to provide an accessible and user-friendly way of displaying the items on the menu.
- Subtle animations, such as a loading spinner during menu loading or a sliding transition for order placement.
